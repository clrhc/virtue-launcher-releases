# VIRTUE launcher

Downloads of the VIRTUE launcher for Windows: one app that installs, updates and starts VIRTUE's games
(Virtue Sekai, Wrong Alley, and Dark Contrition when it ships).

Get the newest from the [latest release](https://github.com/clrhc/virtue-launcher-releases/releases/latest), or
from [virtue.wtf/download](https://www.virtue.wtf/download). Installed launchers update themselves.

Each release lists the SHA-256 of its exe. The launcher checks that hash before replacing itself.
